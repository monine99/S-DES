【第 1 关】基本测试 —— 8 bit 明文 + 10 bit 密钥
----------------------------------------------------------------------------
  密钥扩展：
  密钥 K          = 1010000010
  P10(K)          = 1000001100   (左半 10000 | 右半 01100)
  Shift^1(P10(K)) = 0000111000   -> k1 = 10100100
  Shift^2(P10(K)) = 0010000011   -> k2 = 01000011

  加密过程：
  IP(输入)        = 01011101   (左半 0101 | 右半 1101)
  第 1 轮 密钥    = 10100100   f_k1 = 1111   轮输出 = 10101101
  SW 之后         = 11011010   (左半 1101 | 右半 1010)
  第 2 轮 密钥    = 01000011   f_k2 = 1111   轮输出 = 00101010
  IP^-1 之后      = 00111000

  明文 P          = 10010111
  密文 C          = 00111000

  解密过程：
  IP(输入)        = 00101010   (左半 0010 | 右半 1010)
  第 1 轮 密钥    = 01000011   f_k1 = 1111   轮输出 = 11011010
  SW 之后         = 10101101   (左半 1010 | 右半 1101)
  第 2 轮 密钥    = 10100100   f_k2 = 1111   轮输出 = 01011101
  IP^-1 之后      = 10010111

  解密结果        = 10010111   [与原明文一致]

【第 5 关】封闭测试 —— 是否存在多个密钥对应同一密文
----------------------------------------------------------------------------
  固定明文 P = 10010111，穷举全部 1024 个密钥：

  不同密文个数             = 240 / 256
  只对应 1 个密钥的密文    = 16
  对应 >=2 个密钥的密文    = 224
  落在碰撞里的密钥数       = 1008 / 1024
  单个密文最多对应密钥数   = 12
  平均每个密文对应密钥数   = 4.267
  最拥挤的密文             = 00101100（对应 12 个密钥）

  明文 10010111 -> 00101100 的全部密钥：
      0000001100
      0001000100
      0010101000
      0010111100
      0011100000
      0011110100
      1100000100
      1101001100
      1110100000
      1110110100
      1111101000
      1111111100

  【结论】
    (1) 对同一对明密文，确实存在不止一个密钥：上面 12 个密钥都能把 10010111 加密成 00101100。
    (2) 对任意固定明文，不同密钥加密得到相同密文的情形必然存在：
        1024 个密钥只能产生 240 种密文，按鸽巢原理必然发生碰撞。
    (3) 但这不等于「密钥等价」：进一步分析见 keyspace 子命令。
